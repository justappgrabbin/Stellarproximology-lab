Use the complete Modelmaker-repair directory, including assembly/, computer/, and
vendor/. Copying app.py alone is insufficient.

Private chat setup and usage: PRIVATE-CHAT.md

Python 3.11+ and Node 22+ are required. Install the CPU PyTorch build first,
then requirements.txt. Run: python -m assembly.desktop_server
Open http://127.0.0.1:7860

For the standalone training UI only: python app.py
For the optional local stdio MCP toolbox: python computer/mcp_server.py
